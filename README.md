
# 🏦 Bank Management System

A console-based **Bank Management System built with C++** using **Object-Oriented Programming (OOP)** and **JSON file handling**.

## ✨ Features

* 👨‍💼 Admin login and customer management
* 👤 Customer login
* 💰 Deposit and withdraw money
* 💵 Check account balance
* 📝 Update customer information
* 🔐 Change PIN
* 🧾 View transactions
* 🔒 Block/activate customer accounts
* 💾 Persistent data storage using JSON

## 🛠️ Technologies

* C++
* OOP
* nlohmann/json
* File Handling
* JSON

## 📂 Files

```text
main.cpp
customer.json
transaction.json
nlohmann/json.hpp
```

## 🚀 Run

Compile with:

```bash
g++ main.cpp -o bank_management_system
```

Then run:

```bash
bank_management_system
```

## 🎯 Purpose

This project was created to practice **C++, OOP, file handling, JSON, and basic banking system logic**.
